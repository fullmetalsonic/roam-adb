# RoamADB 제품명·저장소명·아이콘 결정

## 1. 문서 상태

- 상태: 사용자 선택 완료
- Android 앱: `RoamADB`
- Windows 프로그램: `RoamADB Gateway`
- 실행 파일: `RoamADBGateway.exe`
- 저장소: `fullmetalsonic/roam-adb` (Public 예정, 아직 미게시)
- 패키지: `io.github.fullmetalsonic.roamadb`
- 실제 아이콘: 방향 A를 적응형 벡터로 기술 스파이크에 적용
- 상표·GitHub 중복: 1차 검색만 수행, 법적 상표 조사는 미실시

## 2. 이름 기준

- Android 원격 ADB라는 목적을 어느 정도 짐작할 수 있어야 한다.
- 특정 제조사 Fold에만 묶이지 않아야 한다.
- `Tailscale` 상표가 제품명에 직접 들어가지 않아야 한다.
- 저장소명과 패키지명으로 사용하기 쉬워야 한다.
- 한국어와 영어에서 읽기 어렵지 않아야 한다.

## 3. 후보

| 순위 | 이름 | 저장소 후보 | 장점 | 주의점 |
|---|---|---|---|---|
| 1 | RoamADB | `roam-adb` | 밖으로 이동한 폰의 ADB라는 의미가 명확하고 짧음 | 정식 확정 전 상표 추가 확인 필요 |
| 2 | Pocket Debug Link | `pocket-debug-link` | 휴대폰·연결 목적이 분명함 | 이름이 김 |
| 3 | DroidRelay | `droid-relay` | Android relay 기능을 표현 | 다른 relay 제품과 혼동 가능 |
| 4 | Remote ADB Link | `remote-adb-link` | 검색과 이해가 쉬움 | 고유성이 낮음 |

최종 이름은 `RoamADB`이다.

## 4. 패키지명 후보

```text
io.github.<github-owner>.roamadb
```

GitHub 사용자 또는 조직 이름을 확인한 뒤 확정한다. 기존 Tailscale·LADB 패키지명을 사용하지 않는다.

## 5. 표시 문구 후보

- 한국어 짧은 설명: `필요할 때 켜는 안전한 원격 ADB 연결`
- 영어 짧은 설명: `On-demand remote ADB over a private network`
- GitHub 설명: `A single Android app for on-demand remote ADB over an embedded private network.`

## 6. 아이콘 방향 A — 연결 다리

권장안이다.

- 왼쪽의 세로형 둥근 사각형: 휴대폰
- 오른쪽의 작은 사각형: PC
- 두 장치 사이의 아치형 연결선: 사설 연결
- 중앙의 작은 점 또는 체크: 연결 준비
- 단순한 2색 벡터
- 작은 빠른 설정 타일에서도 식별 가능

## 7. 아이콘 방향 B — 분리된 두 포트

- 두 개의 포트 점과 하나의 연결선
- ON일 때 선이 이어지고 OFF일 때 분리되는 모션 가능
- 지나치게 USB 커넥터처럼 보이지 않도록 주의

## 8. 피할 표현

- Tailscale의 3×3 점 배열과 유사한 형태
- Android 로봇을 그대로 사용한 상표 의존 표현
- 벌레, 번개, 해골과 해킹을 연상시키는 과장된 이미지
- 열쇠나 방패만 크게 사용하여 일반 VPN 앱처럼 보이는 구성
- Fold 전용처럼 보이는 접는 휴대폰 실루엣

## 9. 색상 후보

- 기본 배경: 짙은 남색 `#0B1220`
- 연결선: 파랑 `#3B82F6`
- 준비 완료 점: 녹색 `#22C55E`
- 단색 아이콘: 흰색 또는 시스템 테마색

최종 색상은 Android 적응형 아이콘, 밝은/어두운 배경, 고대비와 빠른 설정 타일에서 각각 검증한다.

## 10. 결정 결과

1. `RoamADB` 최종 이름 확정
2. 아이콘 방향 A `연결 다리` 확정 및 1차 벡터 적용
3. GitHub 개인 계정 `fullmetalsonic`, Public 저장소 `roam-adb` 예정
