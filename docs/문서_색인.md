## 4. 현재 승인 경계

사용자는 2026-08-24에 이름과 1차 기술 스파이크 구현을 승인했고, 2026-08-25에 `portable-usb-bridge` 계획의 공개 문서화를 승인했다. 다음은 아직 별도 실행하지 않는다.

- upstream 소스 복제·포크
- Fold8 APK 설치
- 공유기 포트포워딩·Windows 방화벽 변경
- 공유기·공인망 listener 활성화
- 부품 도착 전 Raspberry Pi OS 작성·Bridge Agent 구현
- USB 브리지 지원을 표시하는 새 APK·EXE·Release 생성

## 5. 다음 단계

현재 공개 `v0.1.2-spike` 사용법은 `기존_Tailscale_ADB_전용_모드.md`를 따른다. 하드웨어 경로는 USB ADB, USB 테더링/핫스팟, 독립 인터넷 원격 shell·파일 왕복, 실제 케이블 재연결과 콜드부팅 3회까지 통과했다. 장시간·20회 재연결·10회 부팅과 H-08 PC 도구 통합은 아직 남아 있으므로 새 APK·EXE·Release가 이 경로를 지원한다고 표시하지 않는다.
