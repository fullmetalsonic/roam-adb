# RoamADB 문서 색인

## 1. 현재 단계

- 3차 기존 Tailscale 경유·ADB 전용 기술 스파이크 구현 완료
- Android debug APK·Gateway CLI 생성
- 원격 ADB byte relay와 기존 Tailscale 경로 구현, 실기기 E2E는 미검증
- GitHub Public 저장소와 `v0.1.0-spike` 사전 릴리스 게시·공개 다운로드 검증 완료

## 4. 현재 승인 경계

사용자는 2026-08-24에 이름과 1차 기술 스파이크 구현을 승인했다. 다음은 아직 별도 실행하지 않는다.

- upstream 소스 복제·포크
- Fold8 APK 설치
- 공유기 포트포워딩·Windows 방화벽 변경
- 공유기·공인망 listener 활성화

## 5. 다음 단계

`기존_Tailscale_ADB_전용_모드.md` 순서로 Fold8 ↔ 현재 PC 등록·인증과 표준 PC ADB E2E를 먼저 검증한다. 그 다음 mDNS 자동 탐색과 최초 pairing UI를 진행한다. 공유기·방화벽은 이번 모드에서 변경하지 않는다.
