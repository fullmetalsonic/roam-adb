# RoamADB v0.1.1 요구사항 재감사

- 작성일: 2026-08-25
- 기준: 최초 제품 기획서, 구현 전 승인안, UI/UX 기획서, 동작 기획서, 인증·보안 기획서
- 목적: CLI 전용 `v0.1.0-spike`를 일반 사용자가 실행 가능한 형태로 바로잡고 누락 기능을 추적한다.

| 항목 | 기획 기준 | v0.1.0 상태 | v0.1.1 조치 |
|---|---|---|---|

## 2. v0.1.1 완료 기준

1. EXE를 더블클릭하면 일반 Windows 창이 유지된다.
2. 진단 결과와 Gateway 켜기/끄기 상태가 문구로 구분된다.
3. 등록 버튼을 누르면 PC 주소, 6자리 코드, 만료 남은 시간, QR, 인증서 지문이 함께 보인다.
4. Android는 QR을 검사한 뒤 필드를 채우며, 만료·변조·잘못된 형식은 등록 전에 차단한다.
5. 최초 페어링용 포트 중계와 평상시 연결용 포트 중계를 별도로 실행할 수 있다.
6. PC에서 `adb pair`, `adb connect`, `adb disconnect`, `adb devices`, `scrcpy`를 버튼으로 실행할 수 있다.
7. 설치본은 관리자 권한과 자동 시작을 요구하지 않으며 제거 항목을 제공한다.
8. Gateway 단위·통합 시험, Android 단위 시험·lint·APK 빌드, 설치·실행 시험이 통과한다.

## 3. 이번 빌드에서 자동화하지 않는 항목

- 공유기 포트포워딩과 Windows 방화벽 규칙을 자동으로 바꾸지 않는다.
- Tailscale 계정·기기 인증을 RoamADB가 대신하지 않는다.
- Android 무선 디버깅의 시스템 확인 화면을 우회하지 않는다.
- 실제 Fold8의 Android 17 / One UI 9 종단 간 검증은 APK 설치 후 현장 검증으로 남긴다.
- 내장형 사설망 엔진은 이번 수정 범위가 아니다. 기존 Tailscale 경유 ADB 전용 모드가 권장 경로다.

## 4. QR 데이터 계약

QR은 비밀키나 Tailscale 토큰을 포함하지 않는다.

```text
roamadb://register?v=1&host=<tailnet-ip>&port=47156&fingerprint=<sha256-hex>&code=<6-digits>&mode=existing-vpn-adb-only&expires=<unix-seconds>
```

- 앱은 `scheme`, `host`, 버전, 포트, SHA-256 지문, 6자리 코드, 연결 모드, 만료 시간을 모두 검사한다.
- 2분이 지나거나 알 수 없는 필드 값이면 수동 확인 전에 거부한다.
- 등록 코드는 Gateway에서도 한 번 사용하면 즉시 폐기한다.

## 5. 구현 후 독립 재감사 결과

| 재감사 항목 | 판정 | 확인 증거 |
|---|---|---|
| Windows 일반 프로그램 UI | PASS | 설치본 실제 창 생성·유지, 4개 탭 접근성 트리와 육안 화면 확인 |
| 등록 코드와 QR | PASS | 실제 6자리 코드·01:59 카운트다운·QR·주소·지문 표시, OFF 시 폐기 |
| Android QR 등록 | PASS(코드·빌드) | strict parser 3 tests, Google Code Scanner 연동, 수동 입력 유지; 실제 카메라는 현장 대기 |
| 최초 ADB 페어링 | PASS(코드·빌드) | Android pairing relay와 PC `adb pair` UI 분리; 실제 adbd는 현장 대기 |
| ADB 조작 | PASS(PC UI) | pair/connect/disconnect/devices/scrcpy 버튼과 결과·오류 표시 |
| 등록 기기 관리 | PASS | 등록 목록·새로고침·확인 후 해제 구현 |
| Windows 설치 경험 | PASS | silent install → 실제 실행 → 정상 종료 → uninstall, 오류 이벤트 0 |
| Android 16 기준 | PASS | 모든 Android 모듈 compile/min 36, app target 36, APK manifest 재확인 |
| 단일 실행과 종료 보호 | PASS | 두 번째 실행 안내·첫 창 유지, 두 PID 정상 종료, 오류 이벤트 0 |
| 실제 GUI 검증 | PASS | 최종 후보 1160×800 화면·버튼·상태·잘림·겹침 확인 |

결론: 최초 기획에서 `v0.1.0-spike`에 빠졌던 일반 사용자용 PC 화면과 등록 흐름은 `v0.1.1-spike` 후보에 반영됐다. 남은 항목은 구현 누락이 아니라 Fold8·외부망·실제 adbd가 필요한 현장 E2E다. mDNS 자동 포트 탐색과 내장 Tailscale 원툴 모드는 다음 단계의 편의·확장 기능으로 분리한다.
