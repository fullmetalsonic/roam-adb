# RoamADB v0.1.1-spike

`v0.1.0-spike`의 CLI 전용 Windows 파일을 일반 프로그램형 Gateway로 교체한 기술 사전 릴리스입니다.

## 주요 변경

- Windows 상태 창, Gateway ON/OFF, 진단, 등록 QR와 2분 코드
- Android QR 스캔과 수동 입력 대체
- 최초 무선 ADB pairing relay와 PC `ADB 페어링` 버튼
- 평상시 ADB connect/disconnect/devices와 선택적 scrcpy 버튼
- 등록된 휴대폰 확인·해제
- Android 16(API 36) 이상 빌드 정렬
- 사용자 권한 Windows 설치·제거와 portable EXE
- Android·Windows 공통 연결 다리 아이콘

## 설치 순서

1. PC와 휴대폰에서 공식 Tailscale을 같은 tailnet으로 연결합니다.
2. Windows에서는 `RoamADB-Gateway-Setup-0.1.1-spike.exe`를 설치해 실행합니다.
3. Android에서는 `RoamADB-0.1.1-spike-debug.apk`를 설치합니다.
4. PC Gateway를 켜고 QR을 만든 뒤 Android 앱에서 스캔합니다.
5. 처음 한 번은 Android 무선 디버깅의 pairing 포트와 코드로 페어링합니다.
6. 이후 Android connect 포트를 저장하고 PC의 ADB 연결 버튼을 사용합니다.

## 주의

- EXE는 코드 서명이 없고 APK는 debug 서명입니다.
- Windows SmartScreen과 Android 출처 불명 앱 경고가 나타날 수 있습니다.
- 공유기·방화벽·Tailscale 계정 설정은 자동으로 바꾸지 않습니다.
- 실제 Fold8 외부망 ADB 종단 간 시험은 아직 `현장 검증 필요`입니다.
- ADB 5555, 공유기 DMZ, relay 포트 포워딩을 사용하지 마세요.

자세한 순서는 `docs/기존_Tailscale_ADB_전용_모드.md`, 전체 검증 결과는 `docs/구현_현황_2026-08-25.md`를 참고하세요.
