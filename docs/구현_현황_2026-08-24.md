# RoamADB 기술 스파이크 구현 현황 — 2026-08-24

최종 갱신: 2026-08-25 — 기존 Tailscale 선연결형 ADB 전용 모드 반영

## 1. 이번에 완성된 범위

### Android `RoamADB`

- 패키지 `io.github.fullmetalsonic.roamadb`
- Compose 기반 등록·상태·ON/OFF 화면
- Android 16 미만 사용 차단 안내
- 사용자 요청형 Foreground Service
- 잠금 해제 후 동작하는 Quick Settings TileService
- 부팅 자동시작 없음
- Android Keystore의 ECDSA P-256 휴대폰 신원 키
- Gateway 인증서 SHA-256 고정
- 6자리 등록 코드 전송, challenge-response 인증
- 프로필 저장과 초기화
- 연결 상태 모델 `SETUP_REQUIRED/OFF/STARTING/READY/PC_CONNECTED/RECOVERING/ERROR`
- 연결 취소 뒤 늦은 성공·오류가 상태를 덮지 못하도록 작업 세대 차단
- 사용자가 무선 디버깅 화면의 ADB connect 포트를 저장하는 설정 카드
- 인증 뒤 Gateway에 `connect` relay를 게시하고 휴대폰 `127.0.0.1:<ADB 포트>`로만 연결
- PC 연결 종료 뒤 인증 session과 relay를 재생성하는 복구 상태
- 백업·기기전송 차단 규칙
- `연결 다리` 적응형 벡터 아이콘
- 3개 연결 방법 선택·저장: 집 PC 직접 연결, 내장형 보안망, 기존 VPN 경유·ADB 전용
- 신규 등록 기본값은 `기존 VPN 경유 · ADB 전용`, 기존 저장 프로필은 직접 연결로 호환 해석
- 내장형 보안망은 계획 상태로 표시하고 실행 차단
- 기존 VPN 모드는 공식 Tailscale 앱이 먼저 연결돼 있다는 전제에서 Android 기본 네트워크의 VPN transport를 사전검사
- RoamADB 자체 `VpnService`는 사용하지 않으며 외부 Tailscale을 시작·교체·종료하지 않음
- VPN·ADB 포트·최초 Gateway 연결 사전검사 실패 시 foreground 알림 종료와 빠른 설정 타일 OFF 새로고침

### Windows `RoamADB Gateway`

- .NET 10 CLI와 모듈형 Core
- `doctor`, `fingerprint`, `run`, `register`, `status`
- Windows 현재 사용자 인증서 저장소의 ECDSA Gateway 신원
- 인증서 SHA-256 지문 출력
- 2분·1회용 6자리 코드, 실패 횟수 제한, 메모리에는 SHA-256 digest만 유지
- 등록 휴대폰 공개키 파일 저장
- TLS 1.2/1.3 + 길이 제한 JSON protocol
- ECDSA P-256 challenge-response
- 인증된 세션 ping과 안전한 종료
- 인증 휴대폰이 요청한 동안만 `127.0.0.1:47157` connect relay와 `127.0.0.1:47158` pairing relay 생성
- `relay_ready` 뒤 JSON에서 byte-transparent raw TCP mode로 전환
- 표준 PC `adb.exe`가 ADB pairing·RSA·TLS를 그대로 담당하는 구조
- 휴대폰이 relay 준비를 완료하지 않으면 제한시간 뒤 PC loopback socket 종료
- 기본 모드에서 `127.0.0.1` 외 수신을 코드로 거부
- `run/register/status --tailnet`에서 로컬 `tailscale ip -4` 결과를 읽어 정확한 Tailscale IPv4 하나에만 수신
- tailnet 예약 대역 밖 주소, wildcard와 알 수 없는 노출 정책 거부
- tailnet 모드도 local ADB relay는 계속 `127.0.0.1` 전용이며 공유기·Windows 방화벽 자동 변경 없음

## 5. 보안 판정

- ADB 5555와 DMZ는 사용하지 않았다.
- Gateway 기본값은 loopback이다. 명시적 `--tailnet`만 Tailscale CLI가 반환한 정확한 단일 IPv4에 bind한다.
- `0.0.0.0`, `::`, 일반 LAN·공인 주소는 tailnet 안전 검사에서 거부한다.
- 등록 코드, 개인 키와 인증서 PFX는 파일·Git·로그에 저장하지 않는다.
- Android 개인 키는 Android Keystore에 생성하며 앱 백업을 차단한다.
- PC loopback ADB relay는 인증 휴대폰이 게시한 동안만 존재하고, 휴대폰 미접속 확인에서 닫혀 있었다.
- 현재 APK는 기존 Tailscale 경로의 코드와 PC 측 실행만 검증했다. Fold8 외부망 ADB E2E가 끝난 완성 제품은 아니다.
