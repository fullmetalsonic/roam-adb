# 오픈소스 소스·라이선스 대장

## 1. 문서 상태

- 상태: 자체 인증·raw relay 기술 스파이크 구현, 외부 ADB/Tailscale upstream 미반입
- 고정 커밋: 제3자 소스 반입 전 기록 예정
- 법률 자문: 아님
- 배포 정책: GitHub Public, Google Play 미게시

## 2. 사용 후보

| 구성요소 | 원본 | 라이선스 | 사용 계획 | 필수 조치 |
|---|---|---|---|---|
| Tailscale Android | [tailscale/tailscale-android](https://github.com/tailscale/tailscale-android) | BSD-3-Clause | Android 앱 기반 및 `libtailscale` | 저작권·LICENSE 유지, 이름으로 보증 암시 금지 |
| Tailscale Go 코어 | [tailscale/tailscale](https://github.com/tailscale/tailscale) 계열 | BSD-3-Clause 중심 | 사설망 코어 | upstream 의존성 고지 포함 |
| WireGuard Go | [tailscale/wireguard-go](https://github.com/tailscale/wireguard-go) | MIT | Tailscale 의존성 | MIT 고지 유지 |
| AOSP ADB | [Android Open Source Project ADB](https://android.googlesource.com/platform/packages/modules/adb/) | Apache-2.0 | 무선 ADB TCP·pair/connect 동작의 원본 기술 근거 | 현재 코드 반입 없음; 향후 반입 시 LICENSE·NOTICE와 수정 파일 표시 |
| LADB | [tytydraco/LADB](https://github.com/tytydraco/LADB) | 수정 BSD형, Play 게시 제한 | Android 앱의 localhost 무선 ADB 접속 가능성 교차검증 | 현재 코드·바이너리 반입 없음; 향후 반입 시 LICENSE 유지와 Play 제한 준수 |
| scrcpy | [Genymobile/scrcpy](https://github.com/Genymobile/scrcpy) | Apache-2.0 | PC 화면 보기 도구, 직접 포함 여부 미정 | 재배포 시 고지, 가능하면 공식 설치 안내 |
| AndroidX·Compose | Google AndroidX | Apache-2.0 | UI·생명주기·저장 | 의존성 고지 |

## 3. 참고만 하고 복사하지 않을 후보

| 프로젝트 | 이유 | 허용 범위 |
|---|---|---|
| [djbclark/stayturgid](https://github.com/djbclark/stayturgid) | 명확한 저장소 라이선스 미확인 | 아키텍처·시험 사례 참고 |
| [AndroidGradleTools/adb-relay-android](https://github.com/AndroidGradleTools/adb-relay-android) | 명확한 라이선스 미확인 | outbound relay 아이디어 참고 |
| [PhenixStar/Simple-wireless-ADB](https://github.com/PhenixStar/Simple-wireless-ADB) | 라이선스 불명확 및 문서·코드 경로 불일치 확인 | 위험·시험 사례 참고 |

라이선스가 없는 저장소의 코드, 리소스와 문서를 제품에 복사하지 않는다.

## 4. 프로젝트 자체 라이선스 후보

자체 작성 코드에는 Apache-2.0을 권장한다.

이유:

- AOSP·scrcpy와 친화적이다.
- 수정·재배포 조건이 명확하다.
- 특허 조항을 포함한다.
- GitHub 공개 프로젝트에서 널리 사용된다.

단, 각 제3자 모듈은 원래 라이선스를 그대로 유지하며 LADB가 포함되면 Google Play 게시 제한도 배포 문서에 명시한다.

## 5. 저장소 필수 파일

```text
LICENSE                         # 자체 코드 Apache-2.0 후보
NOTICE                          # AOSP 등 고지
THIRD_PARTY_LICENSES.md         # 모든 제3자 구성요소 목록
third_party/
├─ tailscale/LICENSE
├─ ladb/LICENSE
└─ ...
docs/오픈소스_라이선스_대장.md
```

## 6. 구현 착수 시 기록할 항목

각 upstream마다 다음을 고정한다.

- 원본 URL
- 기준 태그와 커밋 SHA
- 체크아웃 일자
- 원본 LICENSE SHA-256
- 변경 파일 목록
- 빌드 산출물에 포함되는지 여부
- 소스 공개 의무
- 바이너리 고지 위치
- 상표·브랜드 주의사항

## 7. 상표·제품명 원칙

- 제품 이름에 `Tailscale`을 포함하지 않는다.
- Tailscale 공식 앱으로 오해시키는 아이콘·문구를 사용하지 않는다.
- `Powered by open-source Tailscale components`와 같은 출처 표시는 사실에 맞게 별도 정보 화면에 둔다.
- Android 로봇과 기타 브랜드 자산은 각 브랜드 가이드 확인 전 아이콘에 사용하지 않는다.

## 8. GitHub 공개 전 검사

- 실제 키, 토큰, 이메일, 내부 경로 없음
- 회사 데이터·현장 데이터 없음
- LICENSE·NOTICE 누락 없음
- 제3자 저작권 제거 없음
- 고정 커밋과 패치 목록 기록
- Release APK에 오픈소스 정보 화면 포함
- Release 설명에 Google Play 비지원 명시
- 소스에서 재현 가능한 빌드 절차 제공

## 9. 현재 판정

- 기술 검토용 공개 자료: 충분
- 라이선스상 GitHub 배포 가능성: 있음
- 고정 버전별 최종 의무 감사: 미실시
- 자체 코드: Apache-2.0 `LICENSE`, `NOTICE`, `THIRD_PARTY_LICENSES.md` 생성
- Tailscale·LADB·AOSP adb·scrcpy 코드 복사·vendor·link: 미실시
- ADB relay: 공개 원본의 동작만 참고하여 RoamADB 자체 코드로 독립 구현; raw byte를 해석하지 않는 TCP 중계
- AndroidX·Compose·Kotlin 의존성: 패키지 관리자로만 resolve
- GitHub 배포: 미실시
