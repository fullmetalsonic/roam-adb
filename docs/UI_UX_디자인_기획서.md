# RoamADB — UI·UX 목표 기획서

## 1. 문서 상태

- 상태: 승인된 목표안, 1차 Compose 화면·벡터 아이콘 구현
- 실제 UI·이미지: 실기기 캡처 미실행
- 디자인 방향: 전문적, 단순함, 상태 중심, 장식 최소화
- 기준 화면: Fold8 접힘·펼침, Samsung Android 16 이상

현재 실제 화면은 인증 스파이크 범위이며, 아래 전체 UI는 후속 제품 목표다. PC 프로그램의 확정 명칭은 `RoamADB Gateway`이다.

## 3. 홈 화면

### 최우선 정보

1. 현재 상태 문구
2. 큰 ON/OFF 토글
3. 현재 진행 단계
4. PC 접속 여부
5. 문제가 있을 때 해결 버튼

## 4. 상태 표현

| 상태 | 주 문구 | 보조 문구 | 색·형태 |
|---|---|---|---|
| 설정 필요 | 설정을 완료하세요 | VPN과 ADB 페어링 필요 | 중립 카드 + 안내 아이콘 |
| OFF | 원격 디버깅 꺼짐 | 외부 PC에서 연결할 수 없음 | 회색 + 열린 회로 |
| 시작 중 | 연결 준비 중 | 현재 단계 표시 | 파랑 + 진행 표시 |
| READY | 원격 디버깅 준비됨 | 집 PC에서 연결 가능 | 녹색 + 체크 |
| PC 연결 | PC가 연결됨 | PC 이름·접속 시각 | 녹색 강조 + PC 아이콘 |
| 복구 중 | 네트워크 다시 연결 중 | LTE/Wi-Fi 변경 감지 | 주황 + 진행 표시 |
| 오류 | 연결할 수 없음 | 원인과 해결 버튼 | 빨강 + 오류 문구 |

색상만으로 상태를 전달하지 않고 항상 문구와 아이콘을 함께 사용한다.

## 5. 최초 설정 화면

### 공통 구성

- 상단 진행률: `2/5 연결 방식`
- 한 화면에 한 가지 과제만 표시
- 필요한 이유를 두 문장 이내로 설명
- 실제 Android 설정 화면으로 이동하는 버튼
- 돌아왔을 때 자동 재검사
- 성공 후 다음 단계 자동 활성화
- 실패 시 원인별 해결 방법

### ADB 페어링 화면

- `무선 디버깅 설정 열기`
- 페어링 코드 6자리 입력
- 포트 입력 또는 자동 탐지
- 만료까지 남은 시간
- 붙여넣기 지원
- 코드 자체는 저장하지 않음
- Fold 멀티윈도우·팝업 화면 사용 안내

## 6. 빠른 설정 타일

- 레이블: 최종 제품명 또는 `원격 ADB`
- 상태: 꺼짐, 연결 중, 켜짐, 문제 있음
- 짧게 누르기: ON/OFF
- 최초 설정 미완료: 앱 설정 화면 열기
- 길게 누르기: 앱 설정 또는 홈 열기
- 잠금 상태 ON: 잠금 해제 요청
- 접근성: 토글 가능 메타데이터와 상태 설명 제공

## 7. 허용된 PC 화면

각 항목에 다음 정보를 표시한다.

- 사용자가 지정한 PC 이름
- relay 등록 키 또는 Tailscale 장치 신원 일부
- 마지막 접속 시각
- 현재 접속 여부
- 개별 승인 삭제

위험 작업인 `모든 relay 허용 삭제`는 하단 별도 위험 영역에 배치하고 확인 단계를 둔다. Android 시스템 ADB 승인을 취소하려면 개발자 옵션으로 이동하는 별도 안내를 제공한다.

### PC 추가 화면

- `QR 스캔`과 `6자리 코드 입력`을 모두 제공한다.
- QR을 선택할 때만 카메라 권한을 요청한다.
- PC 이름, Tailscale 사용자·태그, 장치 ID 일부와 양쪽 확인 코드를 표시한다.
- `이 PC 허용` 전에는 relay 접근을 열지 않는다.
- 만료·재사용·신원 불일치를 서로 다른 오류로 설명한다.

## 8. 진단 화면

검사 순서는 다음과 같다.

1. Android·One UI 호환성
2. 선택한 연결 모드
3. 직접 PC 주소·포트·외부 도달성 또는 VPN 권한
4. 기존 VPN 경유 모드이면 공식 Tailscale 선연결·split tunneling 상태
5. 직접 tunnel 또는 Tailscale 연결 상태
6. 무선 디버깅
7. 로컬 ADB
8. relay
9. PC 접속
10. 외부 인터페이스 노출

각 검사는 `정상`, `주의`, `오류`, `검사하지 않음`으로 구분한다. 오류에는 해결 버튼을 같은 카드에 배치한다.

## 9. 반응형 기준

- Compact: 폭 600dp 미만, 한 열
- Medium: 600dp 이상 840dp 미만, 상황에 따라 두 열
- Expanded: 840dp 이상, 상태와 상세를 두 열로 표시
- 자세 변화와 회전 중 입력·진행 상태를 보존
- 펼친 화면에서 단순히 카드 폭만 늘리지 않고 정보 영역을 재배치
- 큰 글꼴 200%에서 버튼·문구가 겹치지 않도록 시험

## 10. 상호작용 기준

- 토글 ON/OFF는 1회 누름으로 시작하되 중요한 충돌만 확인한다.
- 시작 중에는 중복 요청을 막고 `취소`를 제공한다.
- 오류 후 사용자가 원인을 고치고 돌아오면 자동 재검사한다.
- Back은 현재 설정 단계를 잃지 않는다.
- Escape·키보드·D-pad 포커스 이동을 지원 가능한 범위에서 시험한다.
- 알림에서 `연결 중지`를 즉시 실행할 수 있다.
