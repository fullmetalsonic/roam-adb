# RoamADB — 구현 전 승인안(승인 이력)

## 1. 승인 목적

이 문서는 실제 구현을 시작하기 전에 사용자에게 확인받았던 최종 요약안이다.

- 승인일: 2026-08-24
- 이름: `RoamADB`, `fullmetalsonic/roam-adb`, `RoamADB Gateway`
- 구현 현황: 인증·ON/OFF 기술 스파이크 APK와 Gateway CLI 생성
- 미실행: Fold8 설치, ADB relay, 공유기 변경, GitHub 게시

## 2. 이미 확정된 사항

- 휴대폰용 단일 APK
- 휴대폰 단일 APK 안에 직접 PC tunnel과 선택적 사설망 공급자 포함
- Galaxy Z Fold8 / Android 17 / One UI 9 기준 개발
- Samsung Android 16 / One UI 8 이상 최소 목표
- 부팅 후 자동연결 없음
- 앱 토글과 빠른 설정 타일로 필요할 때만 ON/OFF
- GitHub Public 공개
- Google Play 미게시

## 3. 승인 요청 추천안

### 3.0 네트워크 기반 — 사용자 선택 필요

- 선택 D: 각 사용자의 집 PC가 직접 인증 서버 — 공인 주소·포트 또는 IPv6 필요
- 선택 A: Tailscale 서비스 이용 — 현재 추천, 자체 서버 불필요
- 선택 B: Headscale 자체 운영 — 자체 제어 서버 필요
- 선택 C: 완전 자체 프로토콜·relay — 개발·운영 범위 가장 큼

집 회선 직접 접속 진단 결과가 양호하면 선택 D를 우선 검토하고, CGNAT 등으로 불가능하면 선택 A를 fallback으로 사용한다.

### 3.1 제품 정체성

- 앱 이름: `RoamADB`
- 저장소명: `roam-adb`
- GitHub 소유자: `fullmetalsonic`
- 패키지명: `io.github.fullmetalsonic.roamadb`
- 아이콘: 휴대폰과 PC 사이를 아치형 연결선으로 잇는 `연결 다리` 디자인
- 언어: 한국어 기본, 영어 동시 제공

### 3.2 1차 버전 기능

- 루팅 없이 동작
- 직접 모드는 PC QR 등록, Tailscale 모드는 VPN 승인·브라우저 로그인
- 최초 1회 무선 ADB 페어링
- 앱 토글과 빠른 설정 타일 ON/OFF
- Wi-Fi/LTE/5G 전환 복구
- 표준 ADB shell·logcat·설치·삭제·push·pull·forward/reverse
- Android Studio 연결
- scrcpy 화면 보기·제어
- relay 허용 PC 목록
- 단계별 진단과 민감정보 제거 보고서
- Windows PC Helper CLI 및 단순 버튼형 UI
- PC Helper QR 또는 6자리 코드 등록
- Tailscale 장치 신원 + relay 허용 목록 + Android 기본 ADB 페어링·키 승인의 3중 인증

### 3.3 제외 기능

- 루팅·Shizuku·Termux 의존
- 부팅 자동시작·Always-on VPN
- 자체 WSS 인터넷 중계 서버
- Headscale
- Wake-on-LAN
- 다기기 관제
- 클라우드 로그·분석·Crash 업로드

### 3.4 보안 기본값

- 전역 ADB 5555를 제품 기본 경로로 사용하지 않음
- Tailnet 전용 relay 우선
- 불가능하면 인증된 outbound tunnel을 PC Helper로 사용
- 일반 LAN·핫스팟·이동통신 인터페이스 노출 시 출시 차단
- 잠금 상태 타일 ON은 잠금 해제 필요
- 다른 VPN은 자동으로 종료하지 않고 충돌 안내
- OFF 시 relay·직접 tunnel 또는 VPN·임시 연결 종료
- 로그인·로컬 페어링·relay 허용 PC는 보존
- 진단 로그는 상태 이벤트만 최대 7일 또는 200건 중 먼저 도달한 범위로 보관
- ADB 명령, 파일·화면 내용, 키와 토큰은 로그에 저장하지 않음

### 1단계 완료 후 중간 보고

- 성공·실패 결과

### 2단계 — 제품 기능·UI

1단계가 통과한 뒤에만 최초 설정, 홈, 빠른 타일, 진단, 허용 PC, 다국어와 Fold 반응형 UI를 구현한다.

## 7. 2026-08-25 휴대형 USB 브리지 승인 경계

현재 무선 ADB 경로가 Fold8 실기기에서 성공한 뒤 LTE/5G 단독 이동 상태의 Wi-Fi 전제조건을 해결하기 위해 `portable-usb-bridge` 계획을 추가 승인했다.

- 기준 하드웨어: Raspberry Pi Zero 2 W
- 데이터 경로: Fold8 USB `adbd` → Pi `adb` → Fold8 2.4GHz hotspot/LTE → Pi Tailscale → 집 PC
- 보안: Android 무선 디버깅 OFF, 폰 루팅 없음, 공인 ADB·5037·5555 listener 없음
- 사용자 진행: 부품을 구매·배송받은 뒤 초보자용 H-00부터 한 단계씩 수행
- 이번 승인: GitHub Public 계획 문서 작성·교차검토·게시
- 이번 미승인: OS 이미지 작성, 설치 스크립트, Bridge Agent, Android·Gateway 코드 변경, 새 APK·EXE·Release

하드웨어 H-00~H-06 E2E 결과를 보고한 뒤 자동화·Bridge Agent·통합 UI 구현 범위를 다시 확인한다.
