## 3. 시험 환경 행렬

### 집 회선 직접 서버 사전검사

- 공인 IPv4와 공유기 WAN 주소 비교
- ISP CGNAT 가능성
- 글로벌 IPv6와 외부 접근
- 수동 포트포워딩
- Windows 방화벽 최소 규칙
- DDNS 주소 갱신
- LTE 휴대폰에서 PC Helper TLS/QUIC handshake
- 미등록 휴대폰 접속 거부

### Android

| 환경 | 용도 | 필수 여부 |
|---|---|---|
| Fold8 / Android 17 / One UI 9 | 기준 실기기 | 필수 |
| Samsung / Android 16 / One UI 8 | 최소 지원 검증 | Public 안정판 전 필수 |
| Android 17 에뮬레이터 | UI·상태·권한 일부 | 보조 |
| 타 제조사 | 범용 확대 | 1차 버전 N/A 가능 |

Android 16 실기기를 확보하지 못하면 `지원 예정·미검증`으로 표시하며 검증 전 정식 지원으로 선언하지 않는다.

### 네트워크

- 집 Wi-Fi ↔ 집 PC
- 외부 Wi-Fi ↔ 집 PC
- LTE ↔ 집 PC
- 5G ↔ 집 PC
- Wi-Fi → LTE 전환
- LTE → Wi-Fi 전환
- 통신 단절 → 복구
- 다른 VPN 활성 상태

### PC

- Windows 11 + 공식 Android Platform-Tools
- Android Studio 최신 안정판
- scrcpy 안정판
- Codex가 사용하는 ADB 경로

## 7. 실기기 최초 설정 E2E

1. 새 설치 상태에서 실행한다.
2. 기본 선택이 `기존 VPN 경유 · ADB 전용`인지 확인한다.
3. 공식 Tailscale 앱을 OFF한 채 등록해 활성 VPN 안내를 확인한다.
4. 공식 Tailscale 앱을 별도로 켜고 로그인을 완료한다.
5. 무선 디버깅이 꺼진 상태의 안내를 확인한다.
6. 설정 화면에서 켠 뒤 앱으로 돌아온다.
7. 잘못된 페어링 코드와 만료 코드를 시험한다.
8. 올바른 코드로 페어링한다.
9. 준비 시험을 완료한다.
10. 앱 종료·재실행 후 설정 보존을 확인한다.

2. 부팅 후 원격 연결이 자동 시작되지 않음을 확인한다.
3. 잠금 해제 후 타일 또는 앱 토글로 정상 시작되는지 확인한다.

## 10. 보안 시험

### PC 등록

- 정상 QR 등록
- 6자리 코드 등록
- 만료 코드 거부
- 같은 코드 재사용 거부
- QR의 PC 이름만 위조한 요청 거부
- Tailscale 장치 신원 불일치 거부
- 등록되지 않은 같은 tailnet 장치 거부
- 허용 PC 삭제 즉시 진행 세션 종료
- Tailscale 노드 키 회전·재인증 후 신원 판정

### 포트 노출

- 집 LAN의 다른 PC에서 휴대폰 물리 IP 포트 스캔
- 휴대폰 핫스팟 클라이언트에서 포트 접근
- Tailscale 미가입 장치에서 접근
- 승인되지 않은 tailnet 장치에서 접근
- Gateway가 Tailscale 단일 IP 외 `0.0.0.0`, LAN·공인 IP bind를 거부
- OFF 상태에서 모든 후보 포트 접근

### 인증

- 승인되지 않은 ADB RSA 키 거부
- relay 허용 PC 삭제 후 relay 재접속 거부
- 앱 relay 허용 목록 초기화 후 접속 거부
- Android 개발자 옵션에서 ADB 승인 취소 후 기존 PC ADB 접속 거부
- Tailscale 로그아웃 후 접속 거부

### 비밀정보

- APK 문자열에서 토큰·키·이메일 검색
- Git history 비밀정보 검색
- 진단 보고서의 키·주소·개인정보 마스킹
- Android 백업에 개인 키 포함 여부
- 로그에 ADB 명령·파일 내용이 남지 않는지 확인

### 실패 안전

- VPN 권한 회수 시 relay 닫힘
- 앱 crash 시 listener 정리
- OFF 일부 실패 시 재시도 후 오류 보고
- 보안 노출 감지 시 즉시 중지
