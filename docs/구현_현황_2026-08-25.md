# RoamADB v0.1.1 기술 스파이크 구현 현황

- 기준일: 2026-08-25
- 대상: GitHub Public `v0.1.1-spike` 후보
- 이전 `v0.1.0-spike`: 프로토콜·CLI 검증용이며 일반 사용자 GUI가 없어 대체 대상

## 1. 완성된 범위

### Windows RoamADB Gateway

- .NET 10 WPF 일반 프로그램 창과 단일 실행 방지
- Tailscale·ADB·저장소·인증서·포트 진단
- 정확한 공식 Tailscale IPv4 하나에 Gateway 시작·정지
- 2분·1회용 6자리 등록 코드, 만료 카운트다운, QR, 주소, 인증서 지문 표시와 복사
- 등록 성공 후 코드·QR 즉시 폐기
- 등록된 휴대폰 목록과 공개키 등록 해제
- ADB pairing/connect/disconnect/devices 버튼과 결과 표시
- 선택적 scrcpy 실행
- 실행 중 창 닫기 확인과 정상 비동기 정리
- per-user Inno Setup 설치·제거, Start Menu, 선택적 바탕 화면 바로가기
- 자동 시작·관리자 권한·방화벽 변경 없음

### Android RoamADB

- Android 16(API 36) 이상 빌드 계약
- 기존 Tailscale 경유·ADB 전용 모드 기본 선택
- Google Code Scanner 기반 QR 스캔, RoamADB 카메라 권한 없음, 수동 입력 대체 유지
- QR의 scheme/version/필드/Tailscale IPv4/포트/지문/코드/모드/만료 엄격 검사
- Android Keystore 휴대폰 개인 키와 PC 인증서 지문 고정
- 등록 휴대폰 challenge-response
- 최초 pairing 포트 입력과 `pairing` relay 열기·중지
- 평상시 connect 포트 저장과 `connect` relay
- 사용자 요청형 foreground service, 알림, 빠른 설정 타일, 자동 시작 없음
- 로컬 adbd는 항상 휴대폰 `127.0.0.1`로만 접근

## 3. 릴리스 후보 산출물

| 파일 | 용도 | 최종 무결성 기준 |
|---|---|---|
| `RoamADB-0.1.1-spike-debug.apk` | Android 16+ debug APK | Release의 `SHA256SUMS.txt` |
| `RoamADB-Gateway-Portable-0.1.1-spike.exe` | Windows x64 무설치 실행본 | Release의 `SHA256SUMS.txt` |
| `RoamADB-Gateway-Setup-0.1.1-spike.exe` | Windows x64 per-user 설치본 | Release의 `SHA256SUMS.txt` |
| `SHA256SUMS.txt` | 위 3개 파일의 소문자 SHA-256 | GitHub 게시 뒤 익명 재다운로드와 대조 |

.NET single-file과 Inno Setup은 빌드 시각·소스 revision 메타데이터로 바이트가 달라질 수 있으므로, 태그할 commit에서 마지막으로 만든 한 세트를 Release 자산으로 고정한다. 소스 문서에 이전 후보 해시를 하드코딩하지 않고 Release에 함께 올린 `SHA256SUMS.txt`를 최종 기준으로 사용한다.

## 4. 수정 과정에서 확인한 재발방지 항목

- CLI를 일반 사용자 배포본으로 간주했던 요구사항 누락을 별도 재감사 문서와 실제 GUI 시험으로 차단했다.
- WPF single-file 게시에는 네이티브 DLL 자체 추출을 강제한다.
- WPF `Closing` 이벤트 안에서 재귀 `Close()`를 실행하지 않고 Dispatcher idle에 종료를 예약한다.
- pairing relay와 connect relay를 Android와 PC 양쪽 UI에서 구분한다.
- Android 앱의 논리적 API 36 차단과 Gradle manifest 빌드 계약을 동일하게 맞췄다.

## 5. 남은 현장 검증

- Fold8 Android 17 / One UI 9에 APK 설치와 QR 카메라 스캔
- 외부 LTE/5G 또는 외부 Wi-Fi에서 PC Gateway 등록·인증
- 실제 Android pairing code와 PC `adb pair 127.0.0.1:47158`
- 실제 `adb connect 127.0.0.1:47157`, shell, logcat, APK 설치, 파일 왕복
- Android Studio, scrcpy, Codex 디버깅
- 화면 잠금, Wi-Fi↔LTE, Tailscale 재연결, 장시간 유지, OFF 후 차단
- Android 16 / One UI 8 태블릿 호환성

실제 휴대폰이 현재 연결돼 있지 않으므로 이 항목들은 PASS가 아니라 `현장 검증 필요`다.

## 6. 보안·배포 판정

- ADB 5555, DMZ, 공유기 포트포워딩, wildcard listener를 사용하지 않는다.
- 코드·개인 키·Tailscale 토큰·회사 데이터는 저장소와 릴리스에 포함하지 않는다.
- EXE는 코드 서명 전, APK는 debug 서명이다. SmartScreen·sideload 경고를 릴리스에 표시한다.
- 공개 저장소 가시성은 사용자가 확정한 Public이다.
- GitHub `v0.1.1-spike` 게시, Actions, 익명 다운로드, 원격 해시는 게시 뒤 최종 확인한다.
