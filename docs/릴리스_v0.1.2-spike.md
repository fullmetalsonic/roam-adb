# RoamADB v0.1.2-spike

Fold8 Android 17 / One UI 9 실제 기기에서 발견한 인증·중계 문제를 수정하고 USB 없는 원격 ADB E2E를 통과한 기술 사전 릴리스입니다.

## 주요 수정

- Android의 DER ECDSA 서명을 Gateway가 표준 `Rfc3279DerSequence`로 검증
- .NET 전용 P1363 시험을 Android와 같은 DER 교차 플랫폼 계약으로 교체
- 휴대폰이 PC 로컬 ADB 접속 전에 중계를 끌 때 loopback listener 즉시 정리
- connect·pairing relay별 직렬 슬롯으로 같은 고정 포트의 안전한 재게시 보장
- 휴대폰 종료 직후 같은 relay 포트를 재게시하는 회귀시험 추가

## 실제 검증

## 설치 순서

1. PC와 휴대폰의 공식 Tailscale을 같은 tailnet으로 연결합니다.
2. `RoamADB-Gateway-Setup-0.1.2-spike.exe`를 설치하고 Gateway를 켭니다.
3. `RoamADB-0.1.2-spike-debug.apk`를 설치합니다.
4. 최초 1회 QR로 PC를 등록하고 Android 무선 ADB를 페어링합니다.
5. 무선 디버깅 메인 화면의 일반 connect 포트를 RoamADB에 저장하고 원격 디버깅을 켭니다.
6. PC의 ADB 작업에서 `ADB 연결`을 누릅니다.

## 알려진 제한

- Android가 Wi-Fi 또는 무선 디버깅 상태 변경 뒤 connect 포트를 바꿀 수 있습니다. 현재 버전은 사용자가 무선 디버깅 화면의 새 일반 포트를 다시 저장해야 합니다.
- LTE/5G만 남긴 상태, 다른 외부 Wi-Fi, 화면 잠금, 장시간 유지, Android 16 / One UI 8은 추가 현장 검증이 필요합니다.
- EXE는 코드 서명이 없고 APK는 debug 서명입니다. Play Store 배포본이 아닙니다.
- ADB 5555, 공유기 DMZ, relay 포트 포워딩을 사용하지 않습니다.
