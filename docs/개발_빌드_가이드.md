# RoamADB 개발·빌드 가이드

## 1. v0.1.2 기준 도구

- Windows 11 x64
- Microsoft OpenJDK 17 또는 21
- Gradle Wrapper 8.13
- Android Gradle Plugin 8.12.2
- Kotlin 2.0.21
- Android SDK Platform 36 / Build Tools 36.0.0
- .NET SDK 10.0.400
- Windows 설치본 생성 시 Inno Setup 6

Android 앱의 `minSdk`, `targetSdk`, `compileSdk`는 모두 36이다. Android 16 / One UI 8 이상을 지원 범위로 두고 Fold8 Android 17 / One UI 9를 우선 실기기로 사용한다.

## 2. Android 빌드

1. Android SDK Platform 36과 Build Tools 36.0.0을 설치한다.
2. JDK 17 또는 21을 설치한다.
3. Git에서 제외되는 `android/local.properties`에 SDK 경로를 기록한다.

```properties
sdk.dir=C\:\\Users\\사용자명\\AppData\\Local\\Android\\Sdk
```

4. 프로젝트 루트에서 실행한다.

```powershell
.\scripts\build-android.ps1
```

스크립트는 전체 모듈 `test`, debug APK assemble, debug lint를 수행하고 다음 파일을 만든다.

- 로컬 APK: `android/app/build/outputs/apk/debug/app-debug.apk`
- 릴리스 후보 복사본: `artifacts/release/RoamADB-0.1.2-spike-debug.apk`

## 3. Gateway 빌드와 시험

```powershell
.\scripts\test-gateway.ps1
```

수행 항목은 Release build, Core 단위·통합 시험, CLI build, 로컬 `doctor`다. 현재 시험에는 등록 코드 1회성, QR 데이터 계약, TLS 지문 고정, 기기 키 인증, 안전한 bind, binary relay, relay timeout이 포함된다.

일반 사용자용 Windows 단일 파일을 만들려면 다음을 실행한다.

```powershell
.\scripts\publish-gateway.ps1
```

산출물:

- 게시 폴더: `artifacts/gateway/win-x64/RoamADBGateway.exe`
- portable: `artifacts/release/RoamADB-Gateway-Portable-0.1.2-spike.exe`

WPF self-contained 단일 파일에는 `IncludeNativeLibrariesForSelfExtract=true`가 필요하다. 이 옵션을 빼면 프레임워크 의존 빌드는 열려도 배포 EXE가 `DllNotFoundException`으로 종료될 수 있다.

## 4. Windows 설치본

Inno Setup이 없다면 설치한다.

```powershell
winget install --id JRSoftware.InnoSetup --exact --scope user
```

설치본 생성:

```powershell
.\scripts\build-installer.ps1
```

산출물은 `artifacts/release/RoamADB-Gateway-Setup-0.1.2-spike.exe`다. 설치 정의는 다음 원칙을 강제한다.

- 현재 사용자 설치, 기본 경로 `%LOCALAPPDATA%\Programs\RoamADB Gateway`
- 관리자 권한 불필요
- 시작 메뉴 바로가기
- 바탕 화면 바로가기는 선택 사항
- 부팅·로그인 자동 시작 없음
- 제거 프로그램 제공
- 방화벽과 공유기 설정 변경 없음

## 5. 릴리스 묶음

Gateway 설치본과 portable을 만든 뒤 Android 빌드를 수행하고 다음을 실행한다.

```powershell
.\scripts\package-release.ps1
```

세 산출물의 SHA-256을 `artifacts/release/SHA256SUMS.txt`에 기록한다. 게시 전 로컬 파일, GitHub Release 다운로드 파일, 체크섬 목록을 서로 대조한다.

## 6. 고급 CLI

GUI가 기본 제품이다. CLI는 문제 진단과 개발용으로 계속 유지한다.

```powershell
.\.tools\dotnet\dotnet.exe run `
  --project .\src\gateway\RoamADB.Gateway.Cli\RoamADB.Gateway.Cli.csproj `
  -c Release -- doctor
```

CLI loopback/tailnet 명령은 `doctor`, `fingerprint`, `run`, `register`, `status`다. 일반 사용자는 설치된 `RoamADB Gateway` 창의 버튼을 사용한다.
